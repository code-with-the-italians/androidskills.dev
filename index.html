// THE IDEA

A trusted home for the skills that drive your agent.

Coding agents are only as good as the instructions you hand them. androidskills.dev collects the ones worth keeping — written by practitioners, checked before they ship.

Maintainer-reviewed

Every submission is reviewed and runs an automated security pass before it lands. “Verified” means something — and it’s the default filter.

Manifest-first

A skill is a folder with a SKILL.md. Name, slug, tags and license are read straight from the manifest — never overwritten in the UI.

Agent-ready install

No npm. Install is a manual .zip drop into your agent’s skills directory — or one command from the CLI (coming).

// HOW IT WORKS

Find it. Read it. Trust it. Install it.

Browsing is anonymous. No account needed to discover and inspect a skill.

// step

Search & refine

Faceted search by category, token size and tags. “Verified only” is on by default; every filter lives in a shareable URL.

// step

Inspect before you trust

Read the manifest, the references and every file in the bundle. Token estimates surface as honest order-of-magnitude bands, not false precision.

// step

Copy the install

Grab androidskills add {slug}, or download the .zip straight into ~/.claude/skills/ or ~/.codex/skills/.

// PRINCIPLES

Built to be trusted with autonomous agents.

Verified by default
Human review plus an automated pass. Unverified skills carry a persistent caution and a report action.
Full provenance
Every skill traces back to its source repo @ commit, so you can verify origin yourself.
Token bands, not guesswork
Every model tokenises differently, so sizes show as ~100s / ~1k / ~10k / ~100k — not to-the-digit fiction.
No package manager
Install is a manual zip drop, or a single static-binary CLI. Never npm.
